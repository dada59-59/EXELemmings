Format : une tuile = 10 lignes × 3 octets (B, G, R), conforme au mode bitmap du TMS3556. La carte est un octet par case (index de tuile). Les données sont exportées telles quelles — elles n'ont pas été testées sur machine.

Usage : enregistrer leveldata.asm a cote du source, puis ajouter #include "leveldata.asm" dans la zone de données (avant #include "mixt_api.asm"). Ne pas coller le contenu dans le programme : l'inclusion permet de regénérer le niveau sans y retoucher.
